## Overview

Conway's Game of Life Extended Rules Canvas is a browser-based cellular automaton playground built around an interactive HTML5 Canvas grid. Create an initial arrangement, run it through successive generations, and see how birth and survival rules affect the resulting behavior.

The simulator supports both well-known patterns and user-defined rule sets. Presets, direct cell editing, variable playback speed, and continuously updated statistics provide a convenient way to study patterns and compare rules including Conway, HighLife, and Maze.

---

## What You Can Do

- Load examples such as gliders, glider guns, pulsars, and acorns
- Define cellular automata with custom B/S notation
- Choose Conway, HighLife, or Maze from the available rule presets
- Run the simulation at any speed from 1 through 30 FPS
- Move forward by exactly one generation with manual stepping
- Paint cells on the Canvas using click-and-drag
- Generate a starting layout with randomly positioned cells
- Track the active generation and number of live cells as the simulation runs

## Frequently Asked Questions

### What systems can run it?

It is designed to run inside a web browser on platforms that support current browser features and HTML5 Canvas.

### Are custom rules supported?

Yes. You can enter any supported B/S rule yourself, or use the built-in Conway, HighLife, and Maze selections.

### How can I change the simulation speed?

Set the speed control to a value between 1 and 30 FPS.

### Is there a manual mode for individual generations?

Yes. The step control advances the simulation one generation at a time, making individual transitions easier to inspect.

### How do I draw a starting configuration?

Click and drag over the Canvas to place cells. You can also use random placement to produce an initial configuration automatically.

### How do I find the current version or project changes?

Open the [latest build](https://dylantuoprice9992.github.io/game-of-life-rules-simulator/) for the hosted application, or visit the [repository](https://github.com/dylantuoprice9992/game-of-life-rules-simulator) to review project changes.

### What can I try if nothing happens when I start it?

Make sure JavaScript is enabled, refresh the page, and check that the browser provides HTML5 Canvas support. When running a local copy, confirm that the project is being served correctly if the browser does not permit the files to be opened directly.
